# sigma-docs

**Temporary** public repo for hosting SVG assets used in CVC docs.

Will be retired once a permanent home is established.

## Usage

Drop SVGs into `images/` and reference them via the GitHub Pages URL:

```
https://cvc-partners.github.io/sigma-docs/images/<filename>.svg
```

Use the Pages URL (not `raw.githubusercontent.com`) — Pages serves SVGs with the correct `image/svg+xml` content type so they render when embedded.
